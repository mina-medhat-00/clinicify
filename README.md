# Clinicify

React front-end for the Clinicify online clinic platform.

## Stack

- React 19 + Vite 8
- React Router 7
- Ant Design 6 + Tailwind CSS 4

## Getting started

```bash
npm install
npm start        # or: npm run dev
```

The app runs at [http://localhost:3000](http://localhost:3000) and expects the
backend API on port `5000` (`http://<hostname>:5000`).

## Scripts

| Command                     | Description                       |
| --------------------------- | --------------------------------- |
| `npm start` / `npm run dev` | Start the Vite development server |
| `npm run build`             | Production build into `dist/`     |
| `npm run preview`           | Preview the production build      |
| `npm run lint`              | Run ESLint                        |
